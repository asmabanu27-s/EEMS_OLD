EEMS is a modular Employee Management / HRMS platform.



\## Technology Stack



\### Frontend

\- React

\- TypeScript

\- Vite

\- Tailwind CSS

\- Shadcn UI



\### Backend

\- Node.js

\- Express

\- TypeScript



\### Database

\- PostgreSQL

\- Prisma ORM



\## Core Modules



\- Authentication

\- Role-Based Access Control

\- Employee Management

\- Attendance

\- Leave Management

\- Documents

\- Timesheets

\- Reports

\- Notifications

\- Audit Logs

\- Settings



\## Attendance



Users can check in at any time because the system supports rotational working schedules.



Working hours are calculated from actual check-in and check-out times.



Default rule:



\- 8 hours or more → Present

\- Less than 8 hours → Absent



The minimum working-hour threshold will be configurable.



\## Export



The system will provide a reusable export mechanism supporting:



\- Excel

\- PDF

\- CSV



Available formats can be selected according to the module.
